# VPTH 7342 Lab Studio

Animated, interactive practice stations and quizzes for VPTH 7342 Anatomic Pathology I, Labs 1–4:

1. Describing lesions (distribution, CLASS-C)
2. Acute cell swelling
3. Necrosis
4. Adaptations, accumulations and calcification

Plus a mixed Exam 1 practice set.

**Open the site:** https://divya-suresh-24.github.io/Pathology/

The whole site is one self-contained file, `index.html`. To update it, replace that file and commit; GitHub Pages republishes in about a minute.

Content is drawn from the course lab keys (Drs. Bell and Cassmann), the CLASS-C guide, and Zachary, *Pathologic Basis of Veterinary Disease*, 7th ed., Ch. 1. All illustrations are original schematics.
